# Proyecto Gestión

Único producto de ZangaTech, destinado a gestionar ventas y clientes de Mercopan.

## Alcance solicitado

Catálogo, registro de usuarios, inicio y cierre de sesión, consulta del perfil, carrito, revisión final y registro de compras.

## Tecnologías

HTML, CSS, JavaScript, JSON, PHP y MySQL/MariaDB. Base independiente: `proyecto_gestion`. JSON se usará para intercambio de datos; SQL para crear el esquema persistente.

## Propuestas por confirmar

Rol administrador para gestionar catálogo, clientes y pedidos; historial personal; modalidad de pago y retiro/entrega; venta por unidad o peso; control de disponibilidad.

## Estado

Definición inicial. Aplicación y SQL pendientes de implementación. No hay funcionalidades validadas como terminadas. El repositorio anterior no se modifica.
